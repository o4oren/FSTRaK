FSTRaK: Automatic Flight Tracker and Logbook

FSTRaK is an automatic flight tracker and logbook for Microsoft Flight Simulator. Install it once and forget it's there—the app silently monitors your flights, tracks them on a map, and saves them to a local logbook.🚀 

Installation
FSTRaK Desktop AppDownload: 

- Get the latest release zip from flightsim.to or GitHub Releases.

- Run: Execute the installer included in the zip file.
- Start FSTRaK; it connects to MSFS automatically when the simulator is running with no configuration needed.

MSFS In-Sim Moving Map Panel (Optional)

Release 3.6.0 added a moving map toolbar panel inside MSFS 2024 that mirrors your FSTRaK map, shows live ATC coverage, and tracks aircraft position.Locate 
- Folder: Find the fstrak-ingame-panel folder inside the zip alongside the installer.
- Copy to Community Folder: Move that folder into your MSFS 2024 Community folder:
For Microsoft Store / Xbox App: %LocalAppData%\Packages\Microsoft.FlightSimulator_8wekyb3d8bbwe\LocalCache\Packages\Community 
For Steam: %AppData%\Microsoft Flight Simulator\Packages\Community 
- Restart MSFS: The FSTRaK Moving Map icon will appear in the in-sim toolbar.🛠️ 

Usage Notes

Desktop App Priority: 
Start FSTRaK on the same PC before launching the in-sim panel.

Troubleshooting: 
The panel displays a "FSTRaK is not running" message if the desktop app is not reachable.

For more details, visit: https://o4oren.github.io/FSTRaK/

FSTRaK

Automatic flight tracker and logbook for Microsoft Flight Simulator. Install it once, forget it's there — FSTRaK silently monitors your flights, tracks them on a map, and saves them to a local logbook.

Download on flightsim.to View on GitHub

Features

✈

Automatic Flight Tracking

Detects takeoff, flight, landing, and shutdown automatically. No buttons to press.

📖

Flight Logbook

Every completed flight is saved to a local SQLite database with route, duration, distance, payload, and more.

🗺

Live Moving Map

Track your aircraft in real time on FAA ArcGIS, OpenAIP, MapTiler, Bing, OpenTopoMap, and more.

📊

Flight Analysis & Scoring

Review each flight with event markers, altitude/speed graphs, landing rate, and a scoring system.

📈

Statistics

Most-flown aircraft, airlines, airports, total distance, average and max payload, and more.

🌐

VATSIM & IVAO Live Traffic

View live pilots and ATC on the map. Click any aircraft or controller for details, frequencies, and flight tracks.

📱

MSFS In-Sim Moving Map

Available as a toolbar panel (MSFS 2020 & 2024) or as an EFB tablet app (MSFS 2024). Shows your chart selection, live ATC coverage, and aircraft position inside the simulator.

🌙

Dark Mode

Full dark theme support.

🔇

Silent & Hands-Free

Starts with Windows, connects to MSFS automatically, and requires no manual intervention to track flights.

Installation

FSTRaK Desktop App

Download the latest release zip from flightsim.to or GitHub Releases.
Run the installer included in the zip. FSTRaK installs to %LocalAppData%\Programs\FSTRaK by default.
Launch FSTRaK. It will connect to MSFS automatically when the simulator is running — no configuration needed.

MSFS In-Sim Moving Map Panel (optional)

Adds a moving map toolbar panel inside MSFS 2024 that mirrors your FSTRaK map, shows live ATC coverage, and tracks your aircraft position.

Locate the addon folder in the zip. It is named fstrak-ingame-panel and sits alongside the FSTRaK installer.
Copy fstrak-ingame-panel into your MSFS 2024 Community folder:
  • Microsoft Store / Xbox App: %LocalAppData%\Packages\Microsoft.FlightSimulator_8wekyb3d8bbwe\LocalCache\Packages\Community
  • Steam: %AppData%\Microsoft Flight Simulator\Packages\Community
Restart MSFS 2024. The FSTRaK Moving Map icon will appear in the in-sim toolbar.
Start FSTRaK on the same PC before launching the panel. The panel displays a "FSTRaK is not running" message if FSTRaK is not reachable.

MSFS 2024 EFB App (optional)

Adds the same moving map as a tablet app on the MSFS 2024 EFB home screen. Use this instead of, or alongside, the toolbar panel.

Locate the addon folder in the zip. It is named fstrak-efb-app and sits alongside the FSTRaK installer.
Copy fstrak-efb-app into your MSFS 2024 Community folder:
  • Microsoft Store / Xbox App: %LocalAppData%\Packages\Microsoft.FlightSimulator_8wekyb3d8bbwe\LocalCache\Packages\Community
  • Steam: %AppData%\Microsoft Flight Simulator\Packages\Community
Restart MSFS 2024. Open the in-sim tablet — the FSTRaK app will appear on the EFB home screen.
Start FSTRaK on the same PC before opening the app. The app displays a "FSTRaK is not running" message if FSTRaK is not reachable.

Release Notes

3.6.1 Latest August 2026
  • Edit Flight — correct a flight's departure and arrival airports from the logbook context menu, with nearest-airport suggestions and ident validation
  • Fuel quantity recorded on every flight event and shown in event popups
  • Touchdown G force captured and shown in flight details and the landing popup; landings scored on the worst of the vertical-speed and G-force ratings
  • Bounce and settle-back protection — brief settle-backs after takeoff are not logged as landings, and bounced touchdowns are merged into a single landing event scored on the hardest impact
  • MSFS 2024 EFB tablet app — the moving map is now available as an EFB app on the tablet home screen, in addition to the existing toolbar panel
  • OpenFlightMaps aeronautical chart overlay support
3.6.0 April 2026

  • In-sim panel: aircraft icon matches the type-specific icon used in FSTRaK's live map (B737, A320, C172, helicopter, and more)
  • In-sim panel: aircraft marker and HUD hidden when no flight is active
  • In-sim panel: FIR/UIR and TRACON boundaries now use the same colors as FSTRaK's light theme
  • In-sim panel: hover tooltip on FIR/UIR shows all controller callsigns and frequencies
  • In-sim panel: approach circles only shown for airports with an APP/DEP controller and no TRACON polygon
  • In-sim panel: custom zoom buttons replacing Leaflet's default control for reliable rendering in Coherent GT
  • In-sim panel: active flight's path drawn on the moving map
  • In-sim panel: "FSTRaK is not running" overlay when the tile server is unreachable

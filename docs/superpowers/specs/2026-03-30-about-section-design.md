# About Section — Design Spec

**Date:** 2026-03-30
**Status:** Approved

## Overview

Add an About section to the SettingsView as a full-width footer row below the existing two columns. Also fix the `VATSpy.dat` update logic to track a GitHub release tag instead of a timestamp, so all three data files have consistent version display.

## Scope

Two changes, both required together:

1. **Fix `DataFileUpdateService`** — migrate `VATSpy.dat` fetch from the VATSIM map_data API to the GitHub release (`vatsimnetwork/vatspy-data-project`), storing a `VatSpyReleaseTag` setting instead of `VatSpyLastUpdated`.
2. **About footer in SettingsView** — full-width panel below the existing setting columns showing app identity, data file version tags, and required attributions.

## VATSpy.dat Fix

### Problem
`UpdateVatSpyDatAsync` currently fetches `VATSpy.dat` from `https://api.vatsim.net/api/map_data/` and stores a last-updated timestamp (`VatSpyLastUpdated`). However, `VATSpy.dat` is a release asset in `vatsimnetwork/vatspy-data-project` — the same repo as `Boundaries.geojson` — and carries a proper release tag (e.g., `v2602.2`).

### Fix
- Replace `UpdateVatSpyDatAsync` to use `GetLatestGitHubReleaseAssetAsync("vatsimnetwork", "vatspy-data-project", "VATSpy.dat")` — same pattern as `UpdateFirBoundariesAsync`.
- Add a new user setting `VatSpyReleaseTag` (string, default empty) in `Settings.settings` and `Settings.Designer.cs`.
- Store the release tag on success; use it for staleness check (skip download if tag matches and file exists).
- The old `VatSpyLastUpdated` setting is no longer written but can remain in Settings for backward compatibility (it will simply be ignored).

## About Section

### Placement
Full-width footer row spanning both columns at the bottom of `SettingsView`. The existing XAML outer `StackPanel` (currently `Orientation="Horizontal"`) is wrapped in a vertical `StackPanel` or `DockPanel` so the footer can sit below.

### Layout (three groups, horizontal, flex-like)

| Group | Content |
|-------|---------|
| App identity | App name ("FSTrAk"), version from `AssemblyInfo` (e.g., "v3.2.1"), one-line description, GitHub hyperlink |
| Data Files | Three rows: FIR Boundaries / TRACON Boundaries / VATSpy — each with its release tag read from `Properties.Settings` |
| Credits | VATSpy Data Project by VATSIM Network (CC BY-SA 4.0), SimAware TRACON Project by VATSIM Network (CC BY-SA 4.0), Airport icons by Freepik — Flaticon |

### ViewModel changes (`SettingsViewModel`)

Add four read-only properties (populated in `SettingsView_OnLoaded`):

| Property | Source |
|----------|--------|
| `AppVersion` | `System.Reflection.Assembly.GetExecutingAssembly().GetName().Version` formatted as `"v{Major}.{Minor}.{Build}"` |
| `FirBoundaryTag` | `Properties.Settings.Default.FirBoundaryReleaseTag` (empty string fallback: `"—"`) |
| `TraconBoundaryTag` | `Properties.Settings.Default.TraconBoundaryReleaseTag` (empty string fallback: `"—"`) |
| `VatSpyTag` | `Properties.Settings.Default.VatSpyReleaseTag` (empty string fallback: `"—"`) |

No commands needed — the footer is display-only.

### XAML changes (`SettingsView.xaml`)

- Wrap the existing `<StackPanel Orientation="Horizontal">` (the two columns) in a `<DockPanel>`.
- Add a footer `<Border>` docked to the bottom with `DockPanel.Dock="Bottom"`.
- Inside the footer: a horizontal `StackPanel` with three `StackPanel` children for the three groups.
- Use existing `DynamicResource` brushes: `MainWindowBackground` or similar for background, `TextColor` for values, a dimmed variant for labels.
- GitHub link: use `<Hyperlink>` with `NavigateUri` and a `RequestNavigate` handler in code-behind that calls `Process.Start`.

### Settings changes

- Add `VatSpyReleaseTag` (string, default `""`) to `Settings.settings`.
- `Settings.Designer.cs` is auto-generated — regenerated by Visual Studio when `Settings.settings` is saved.

## What is NOT in scope

- No new ViewModel class — properties go directly on `SettingsViewModel`.
- No library list beyond the three attribution-required credits.
- No "check for updates" button or live refresh of data file tags in the About section (tags shown are what was last downloaded).
- No removal of `VatSpyLastUpdated` from Settings (left as dead setting for backward compatibility).

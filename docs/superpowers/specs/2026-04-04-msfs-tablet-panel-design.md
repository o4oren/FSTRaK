# MSFS Moving Map Tablet Panel — Design Spec

**Date:** 2026-04-04
**Status:** Approved
**Scope:** Subsystem 2 of 2 (Subsystem 1 is the tile server — merged in PR #42)

---

## Problem

FSTRaK now exposes map tiles and ATC network state via a local HTTP tile server (port 8765). There is no way to consume this inside MSFS itself. Pilots who want a moving map while flying must alt-tab to FSTRaK or use a separate device.

---

## Goals

- Provide a moving map panel inside MSFS 2024 that shows the currently selected FSTRaK map, ATC coverage, and controlled airports.
- Package it as a standard MSFS Community addon that users copy to their Community folder.
- Include the addon in FSTRaK's distribution zip.
- Document installation in the repo README and a dedicated install guide.

---

## Architecture

Three independent deliverables:

1. **`index.html`** — the entire panel: self-contained HTML/CSS/JS with Leaflet.js inlined. No build step, no CDN dependencies. Reads tiles from `http://localhost:8765/`, reads SimVars via Coherent GT's `SimVar.GetSimVarValue`.

2. **MSFS addon package** (`msfs-addon/fstrak-moving-map/`) — `manifest.json`, `layout.json`, and the panel HTML. Copied to MSFS Community folder to enable the panel.

3. **`generate_layout.py`** — a Python script that scans the addon folder and writes `layout.json` with correct file sizes and modification times. Run manually before each release.

Additionally:
4. **Tile server API extension** — `NetworkStateHandler` gains an `airports` array in the `/network/state` response.
5. **Documentation** — `msfs-addon/README.md` (install guide) + `README.md` updates.

## Component Design

### 1. MSFS Addon Package

**`manifest.json`:**
```json
{
  "dependencies": [],
  "content_type": "PANEL",
  "title": "FSTrAk Moving Map",
  "manufacturer": "FSTrAk",
  "creator": "FSTrAk",
  "package_version": "1.0.0",
  "minimum_game_version": "1.0.0",
  "release_notes": {
    "neutral": {
      "LastUpdate": "",
      "OlderHistory": ""
    }
  }
}
```

**`layout.json`:** Generated by `generate_layout.py`. Contains a `content` array where each entry has `path`, `size`, and `date` fields. MSFS will refuse to load the addon if this file is missing or stale.

**`generate_layout.py`:** Walks `fstrak-moving-map/`, skips `layout.json` itself, writes entries with `os.path.getsize` and `os.path.getmtime`. Called manually: `python generate_layout.py` from the `msfs-addon/` directory.

### 2. `/network/state` API Extension

Add an `airports` array to the existing response:

```json
{
  "atcVisible": true,
  "network": "vatsim",
  "firs": [ ...existing... ],
  "airports": [
    {
      "callsign": "LLBG",
      "lat": 32.011,
      "lon": 34.886,
      "controllers": [
        { "callsign": "LLBG_APP", "frequency": "119.700", "type": "APP" },
        { "callsign": "LLBG_TWR", "frequency": "121.000", "type": "TWR" }
      ],
      "atis": "INFO ALPHA: RWY 26L IN USE...",
      "polygon": [[34.8, 31.9], [34.9, 32.1], ...],
      "radius": 25
    }
  ]
}
```

Fields:
- `callsign` — airport ICAO (`VatsimControlledAirport.Airport.ICAO`)
- `lat`, `lon` — airport location
- `controllers` — array of active controllers, each with `callsign`, `frequency`, `type` (position type: APP, TWR, GND, DEL, CTR)
- `atis` — VATSIM: joined `text_atis` lines from `VatsimControlledAirport.Atis`; IVAO: `null` (requires separate API call, out of scope)
- `polygon` — GeoJSON coordinate array from `TraconPolygons[0]` if `IsShowTraconPolygon` is true; `null` otherwise
- `radius` — `25` (nautical miles) if no polygon available, used by the panel to draw a Leaflet circle; `null` if polygon is present

Source data:
- **VATSIM:** `LiveViewViewModel.VatsimControlledAirports` — only included when `IsVatsimActive && IsShowVatsimAtc`
- **IVAO:** `LiveViewViewModel.IvaoAtcList` filtered to non-CTR entries (airport-type items) — included when `IsIvaoActive && IsShowIvaoAtc`

### 3. Panel (`index.html`)

Single self-contained file. Leaflet.js (~140KB) is inlined as a `<script>` block. No external resources.

#### Tile Layers

Three stacked Leaflet `TileLayer`s:
1. **Base:** `http://localhost:8765/tiles/base/{z}/{x}/{y}` — always shown
2. **Chart overlay:** `http://localhost:8765/tiles/overlay/chart/{z}/{x}/{y}` — `errorTileUrl` set to a 1×1 transparent PNG so missing tiles (404) render as transparent, not broken
3. **OpenAIP:** `http://localhost:8765/tiles/overlay/openaip/{z}/{x}/{y}` — same transparent fallback

#### Aircraft Marker

SVG airplane icon (top-down silhouette, ~24×24px) as a Leaflet `DivIcon`. Rotated via CSS `transform: rotate(Ndeg)` to match magnetic heading. Always rendered on top (`zIndexOffset: 1000`).

#### SimVar Polling

`setInterval` every 1000ms:
```javascript
const lat  = SimVar.GetSimVarValue("PLANE LATITUDE", "degrees");
const lon  = SimVar.GetSimVarValue("PLANE LONGITUDE", "degrees");
const hdg  = SimVar.GetSimVarValue("PLANE HEADING DEGREES MAGNETIC", "degrees");
const alt  = SimVar.GetSimVarValue("INDICATED ALTITUDE", "feet");
const spd  = SimVar.GetSimVarValue("AIRSPEED INDICATED", "knots");
```

Updates aircraft marker position, heading rotation, and HUD text.

#### Lock / Pan Behavior

`userPanned = false` on init. Map starts centered on aircraft. On Leaflet `dragstart` or `zoomstart` events: set `userPanned = true`, show re-center button. Re-center button click: `map.setView([lat, lon], map.getZoom())`, `userPanned = false`, hide button.

#### ATC Layer

`setInterval` every 30s calls `fetch("http://localhost:8765/network/state")`:

**FIRs:** Leaflet `Polygon` for each feature in `firs[]`. Style: semi-transparent blue fill, 1px blue border. Tooltip shows callsign.

**Airports:** For each entry in `airports[]`:
- Dot marker at `[lat, lon]` — small circle SVG icon
- If `polygon` present: Leaflet `Polygon` with semi-transparent fill
- If no polygon: Leaflet `Circle` with `radius` converted from nm to metres (`radius * 1852`)
- Click opens a popup:
  ```
  LLBG
  LLBG_APP  119.700  APP
  LLBG_TWR  121.000  TWR
  ─────────────────────
  ATIS INFO ALPHA:
  RWY 26L IN USE...
  ```
  ATIS section omitted if `atis` is null.

ATC toggle button calls `fetch("http://localhost:8765/network/atc/toggle", { method: "POST" })` and re-fetches state immediately.

#### HUD

Fixed `position: absolute; top: 0` bar:
```
ALT: 4500 ft    GS: 145 kt    HDG: 275°
```
Dark semi-transparent background, white monospace text. Does not interfere with map interaction.

#### Re-center Button

Fixed `position: absolute; bottom: 40px; right: 10px`. Hidden when `userPanned = false`. Airplane icon (✈). On click: re-center map on aircraft, hide button.

#### ATC Toggle Button

Fixed `position: absolute; bottom: 80px; right: 10px`. Always visible when `atcVisible`. On click: toggle ATC. Icon: radar symbol (◉).

### 4. `generate_layout.py`

```python
import os, json, time

addon_dir = os.path.join(os.path.dirname(__file__), "fstrak-moving-map")
content = []

for root, dirs, files in os.walk(addon_dir):
    for fname in files:
        if fname == "layout.json":
            continue
        fpath = os.path.join(root, fname)
        rel = os.path.relpath(fpath, addon_dir).replace("\\", "/")
        content.append({
            "path": rel,
            "size": os.path.getsize(fpath),
            "date": int(os.path.getmtime(fpath) * 10000000) + 116444736000000000
        })

layout = {"content": content}
with open(os.path.join(addon_dir, "layout.json"), "w") as f:
    json.dump(layout, f, indent=2)
print(f"layout.json written with {len(content)} entries.")
```

### 5. Installation Guide (`msfs-addon/README.md`)

Contents:
1. Prerequisites: FSTRaK v3.5.x or later installed and running
2. Enable tile server: Settings → Enable Tile Server checkbox
3. Copy `fstrak-moving-map/` folder to your MSFS Community folder
4. In MSFS: add the panel to a custom aircraft or use the EFB toolbar
5. Verify tile server is running: `http://localhost:8765/tiles/base/5/20/13` in a browser

---

## Out of Scope

- IVAO ATIS (requires separate authenticated API call per session ID)
- MSFS 2020 compatibility (different panel manifest format)
- Auto-regeneration of `layout.json` via MSBuild
- Vector tile support
- Weather overlay
- Flight plan display
